## 130–180ms 是什么水平，谁会在意

法兰克福到国内的物理距离摆在那里，延迟不可能压到香港、日本机房那种量级。第三方测评给出的数字是：电信走 GIA 去程回程 **130–180ms**，联通去程同样走 GIA，表现接近电信；移动去程是直连、回程才切到 GIA，晚高峰可能有波动。

另一份资料写“三网全走 CN2 GIA、稳定 120–150ms”，和移动缺乏 GIA 去程产品的现状不符，我倾向于前一种描述。测试 IP 是 **185.217.109.94**，下单前自己 ping 一遍，比看任何测评都准。

这个延迟适合什么？网页访问、SSH 操作、API 调用、后台同步这类场景，130–180ms 用起来不难受。不适合什么？实时对战游戏、视频会议、需要 30–50ms 的语音链路，德国机房做不到，换香港或东京的机房才有意义。

GIA 解决的是丢包和绕路，物理距离带来的延迟它改不了。有测评提到普通直连线路晚高峰丢包能到几十个百分点，GIA 线路的意义在于晚高峰不塌，而不是把 180ms 变成 50ms。如果你买它是为了“德国节点还能有低延迟”，预期需要调整；如果你要的是一个晚高峰不抽风的欧洲落地，这条线路对得起价格。

顺带说一个反直觉的地方。月付套餐里，4GB 内存以下统一给 300Mbps，4GB 及以上给 500Mbps，年付 mini 系列反而标着 1000Mbps。带宽在这个产品线上不是按内存线性递增的，低配年付拿到的带宽比高配月付还宽。

**需要 30–50ms 延迟的人**。游戏加速、实时语音、远程桌面重度使用，德国机房全部不合格。这不是线路问题，换任何一家德国机房都一样。

**坚持用信用卡、PayPal 或加密货币付款的人**。这家主打支付宝，其他支付渠道的可用性没有官方说明。

**需要 cPanel、Plesk 这类成熟面板的人**。提供的是简化版管理面板，够用，功能比不上商业面板。

**想跑满大带宽下载的人**。不限流量四档的带宽只有 30Mbps 到 200Mbps，价格从 1200 元/月起。真要跑量，先算清楚 1200 元/月换来 30Mbps 是否划算，多数个人用户用不到这个级别。

## 常见问题

**只有支付宝，没有信用卡，能下单吗？**
能。结账页可以选支付宝扫码付款，全程不需要绑卡。是否只支持支付宝这一种方式，官方没有明确说明，你要用别的渠道先问客服。

**付完多久能开通？**
第三方测评说 10 分钟内自动开通，未获官方确认。付款后订单状态没变化，先等几分钟再看，别重复下单。

**能退款吗？**
有第三方测评称一般支持 7 天无条件退款，官方条款页未见明确说明。金额较大或用途关键时，下单前问清退款条件和流程。

**续费会涨价吗？**
据第三方测评，续费价格与首付一致，全年几乎不发优惠码，也没有大促窗口。这是二手信息，长期使用前建议跟客服确认一次。

**流量是单向还是双向计费？**
资料口径不一，有写“双向 800GB”，有只写“月流量”。流量吃得比较满的话必须问清楚，双向计费意味着实际可用量减半。

**季付 99 元那档一直有吗？**
不保证。有测评提到这类限量季付套餐补货后很快卖完，且 99 元可能是活动价。看到有货可以先拿它试一个月，满意再转年付。

**移动用户能用吗？**
可以，但移动去程是直连、回程才走 GIA，晚高峰体验不如电信和联通稳定。移动宽带用户对延迟敏感的话，先用测试 IP 自己 ping 一轮再决定。
